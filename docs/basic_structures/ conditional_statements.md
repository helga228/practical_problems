# Условные операторы

```
    // if-else
    if x > 0 {
        // ...
    } else if x == 0 {
        // ...
    } else {
        // ...
    }
    
    // if с короткой инструкцией
    if err := doSomething(); err != nil {
        log.Fatal(err)
    }
```

## Как это работает?

### if

После ключевого слова "if" пишем условие, при выполнении которого выполнится код в фигурных скобках. 
Соответственно, если условие после "if" не выполняется, блок в фигурных скобках пропускается.

```
    x := 1
    
    if x > 0 {
        // 1 > 0, а значит код который будет тут - выполнится
    } 
    
    if x == 0 {
        // 1 != 0, а значит код который будет тут - не выполнится
    } 
    
```
### else if

После фигурных скобок нашего условия можно указать "else if <новое условие>", при выполнении которого так-же выполнится 
код в фигурных скобках после условия. Не обязательно использовать "else if", можно просто написать новое условие через "if".

```
     x := 1
     
    if x < 0 {
        // 1 > 0, а значит код который будет тут - не выполнится
    } else if x == 1 {
        // 1 == 0, а значит код который будет тут - выполнится
    } 
    
```

Что равносильно записи

```
     x := 1
     
    if x < 0 {
        // // 1 > 0, а значит код который будет тут - не выполнится
    } 
     
    if x == 1 {
        // 1 == 0, а значит код который будет тут - выполнится
    } 
    
```
### else

Так-же, если есть код, который должен выполниться если условие в "if" не выполнено, мы можем использовать ключевое
слово "else"

```
    x := 1
    
    if x == 0 {
         // 1 > 0, а значит код который будет тут - не выполнится
    } else {
        // код который будет тут выполнится, поскольку ословие выше ложно
    }
    
```

### if с короткой инструкцией

```
    x := 0
    
    if err := doSomething(x); err != nil {
        log.Fatal(err)
    }
```

В данном примере функция doSomething() возвращает error, то есть ее код выглядит примерно так:

```
    func doSomething(x int) error {
    
        if x == 0 {
            return nil
        }
        
        return errors.New("x не равно 0")
    }
```

То есть она может вернуть ошибку, а может nil, и вот что будет в разных случаях

```
    x := 0
    y := 1
    
    if err := doSomething(x); err != nil {
        log.Fatal(err) // условие не выполнится, поскольку x == 0, и функция вернет nil, а выше мы указали условие err != nil
    }
    
     if err := doSomething(y); err != nil {
        log.Fatal(err) // условие выполнится, поскольку y != 0, и функция вернет ошибку, а выше мы указали условие err != nil
    }
```
