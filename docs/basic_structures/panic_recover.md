## Как это работает?

### Panic

Паника - это аварийное завершение работы сервиса. В случае срабатывания паники приложение завершает свою работу, но перед этим 
выполняет все defer имеющиеся в цепочке. 
Пример использования:

```
func main() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Восстановлено после:", r)
        }
    }()
    
    panic("something went wrong")
    // Код здесь не выполнится
}
```

recover используется для востановления работы, он обязательно должен быть указан в defer, иначе просто не выполнится

Паники следует использовать только в случае критичных ошибок, из-за которых продолжение работы не имеет смысла

Что происходит при панике:

1. Создается объект паники
2. Прекращается выполнение текущей функции
3. Выполняются все defer в текщей функции
4. Переход к вызывающей функции
5. Повтор 3 и 4 шага, пока не найдетcя recover
6. Если recover не найдет - аварийное завершение программы
